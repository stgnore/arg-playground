# 千本鏡会 — Senbon Kagami-kai

Одностраничный ARG-сайт с эстетикой закрытой японской технокорпорации: строгая чёрно-белая палитра, ASCII-анимация ворот тории, часы узла и локальная симуляция запроса доступа.

## Запуск локально

Откройте `index.html` в браузере. Для Google Fonts требуется интернет; без него сайт использует системные моноширинные и sans-serif шрифты.

## Публикация на GitHub Pages

1. Создайте новый публичный репозиторий на GitHub.
2. Загрузите в корень репозитория `index.html`, `style.css`, `script.js`, `favicon.svg` и `README.md`.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`, затем нажмите **Save**.
5. Через некоторое время GitHub Pages покажет URL опубликованного сайта в этом же разделе.

## Важно про форму

Это фронтенд-симуляция для ARG. Форма не отправляет данные на сервер и ничего не сохраняет; введённый пароль очищается после отправки. Не используйте настоящие логины и пароли. Чтобы подключить реальную систему аутентификации, нужен отдельный серверный компонент и безопасная реализация авторизации — не храните секреты в клиентском JavaScript.

## Настройка сюжета

- ASCII-кадры и строки протокола находятся в `script.js`.
- Тексты, блоки сайта и поля формы — в `index.html`.
- Цвета, размеры и адаптивная верстка — в `style.css`.
