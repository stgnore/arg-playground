# 千本鏡会 — Senbon Kagami-kai ARG

Адаптивный статический сайт для ARG. Белый фон, чёрная типографика, полноэкранная canvas-анимация ASCII-врат тории, тестовый вход `admin / admin`, внутренний архив и симулируемые каналы связи. На последнем экране `home.html` находится интерактивное зеркало с перевёрнутыми подсказками. Прямая ссылка на следующую главу намеренно отсутствует: игроки должны восстановить имя страницы по подсказке.

## Быстрый запуск

Для проверки запустите локальный веб-сервер из папки проекта: `python -m http.server 8000`, затем откройте `http://localhost:8000`. Сначала появляется полноэкранная ASCII-анимация тории, затем экран логина. При верных тестовых данных браузер перейдёт на отдельную страницу `home.html`.

## Тестовый вход

- **Логин:** `admin`
- **Пароль:** `admin`

Чтобы изменить их, откройте `script.js` и найдите настройки в начале файла:

```js
const TEST_CREDENTIALS = {
  username: "admin",
  password: "admin"
};
```

Замените оба значения на нужные. Проверка работает только в браузере и годится для ARG-прототипа, а не для защиты реальных аккаунтов. Пароль не отправляется и не сохраняется.

## Зеркало и следующая глава

В конце `home.html` находится зеркало. Наведите на него курсор (или коснитесь его на сенсорном экране): поверхность бликует, появляются строки `htorihpeSfOeerT` и `иртомсоП`, а затем предупреждение. Прямая ссылка не показывается: путь следующей главы необходимо восстановить из перевёрнутой надписи и ввести вручную в адресную строку.

В следующей главе можно открыть десять узлов схемы, прочитать их фрагменты и назвать отсутствующий узел DA’AT. После этого открывается протокол первого контакта АДАМ-1, а в самой нижней части находится повторяющаяся запись и HTML-атрибут-заглушка для будущей Imgur-подсказки: `data-imgur-cipher="PASTE_IMGUR_CIPHER_URL_HERE"`.

## Публикация через GitHub Pages

1. Создайте новый репозиторий на GitHub.
2. Загрузите **все файлы** из этой папки в корень репозитория.
3. Откройте **Settings → Pages**.
4. Выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`.
5. Нажмите **Save** и откройте опубликованную GitHub Pages ссылку.

Имена файлов регистрозависимые: не меняйте `TreeOfSephiroth.html` на другое написание без изменения ссылок.

## Структура проекта

- `index.html` — интро с ASCII-вратами и форма тестового входа.
- `home.html` — внутренний архив, чат, фрагмент и зеркало внизу страницы.
- `TreeOfSephiroth.html` — вторая глава ARG с интерактивным Деревом Сефирот.
- `style.css` — стили страниц, адаптивная вёрстка и анимации.
- `script.js` — интро и проверка тестовых данных.
- `home.js` — архивные записи, чат-симуляция и анимация зеркала.
- `sephiroth.js` — взаимодействия узлов и сюжетная расшифровка главы 02.
- `favicon.svg` — минималистичная иконка организации.

## Внутренний чат

Каналы `KAGAMI-7`, `MIRROR-TEST`, `OPS-EAST` содержат реплики агентов разных рангов, появляющиеся с задержками. Это сценарная локальная симуляция: сообщения не передаются другим посетителям. Для общего чата между реальными посетителями понадобится серверная realtime-служба, например Supabase или Firebase, с настроенными правилами доступа.

## Примечание по безопасности

Тестовая авторизация и ключ главы находятся во фронтенд-коде, поэтому их может увидеть любой посетитель. Это намеренно сделано для ARG-прототипа на GitHub Pages. Не используйте эту проверку для приватных или реальных данных.
