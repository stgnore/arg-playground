# 千本鏡会 — Senbon Kagami-kai ARG

Адаптивный статический сайт для ARG. Белый фон, чёрная типографика, полноэкранная анимация ASCII-врат тории, тестовая авторизация и внутренняя главная страница организации.

## Быстрый запуск

Для проверки лучше запустить локальный веб-сервер из папки проекта: `python -m http.server 8000`, затем открыть `http://localhost:8000`. Сначала появляется полноэкранная ASCII-анимация тории; затем — экран логина. При верных тестовых данных браузер перейдёт на отдельную страницу `home.html`. Переход с анимации можно пропустить кнопкой внизу экрана.

## Тестовый вход

- **Логин:** `admin`
- **Пароль:** `admin`

Чтобы изменить их, откройте `script.js` и найдите настройки в самом начале файла:

```js
const TEST_CREDENTIALS = {
  username: "admin",
  password: "admin"
};
```

Замените оба значения на нужные. Важно: проверка находится во фронтенд-коде, который может прочитать любой посетитель. Такой вариант годится только для ARG-прототипа и не является безопасной авторизацией настоящих аккаунтов. В `sessionStorage` записывается только флаг текущего сеанса и декоративный номер сеанса; сам пароль не отправляется и не сохраняется. Эту проверку можно обойти, поэтому не используй её для защиты реальных данных.

## Публикация через GitHub Pages

1. Создайте новый репозиторий на GitHub.
2. Загрузите в корень репозитория все файлы проекта: `index.html`, `home.html`, `style.css`, `script.js`, `home.js`, `favicon.svg` и `README.md`.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** укажите источник **Deploy from a branch**.
5. Выберите ветку `main` и папку `/ (root)`, затем нажмите **Save**.
6. После завершения публикации GitHub покажет ссылку на страницу в этом же разделе.

## Структура

- `index.html` — полноэкранная анимация тории и форма входа.
- `home.html` — отдельная главная страница организации с внутренним архивом.
- `style.css` — оформление всех страниц, адаптивная верстка и анимации.
- `script.js` — анимация входа и проверка тестовых данных.
- `home.js` — защита перехода в рамках ARG-прототипа, архивные документы, сюжетные фрагменты и выход из сеанса.
- `favicon.svg` — минималистичная иконка.

Внешний шрифт загружается из Google Fonts; при отсутствии сети используются системные моноширинные и sans-serif шрифты.
